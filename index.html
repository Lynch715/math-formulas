一、四则运算与运算定律10 条

  • 加法交换律a + b = b + a
  • 加法结合律(a + b) + c = a + (b + c)
  • 乘法交换律a × b = b × a
  • 乘法结合律(a × b) × c = a × (b × c)
  • 乘法分配律(a + b) × c = a × c + b × c逆用：ac + bc = (a+b)c
  • 减法的性质a − b − c = a − (b + c)连减等于减去和
  • 除法的性质a ÷ b ÷ c = a ÷ (b × c)
  • 加减法各部分关系和 = 加数 + 加数加数 = 和 − 另一个加数差 = 被减数 − 减数被减数 = 差 + 减数
  • 乘除法各部分关系积 = 因数 × 因数因数 = 积 ÷ 另一个因数被除数 = 商 × 除数 + 余数
  • 有余数的除法余数 < 除数
提醒　运算顺序：先算括号里的，再算乘除，最后算加减；同级运算从左到右。

二、数的认识与整除11 条

  • 因数与倍数若 a ÷ b = c（无余数），则 b、c 是 a 的因数，a 是 b、c 的倍数
  • 2 的倍数特征个位是 0、2、4、6、8
  • 5 的倍数特征个位是 0 或 5
  • 3 的倍数特征各位数字之和是 3 的倍数
  • 9 的倍数特征各位数字之和是 9 的倍数
  • 4 / 25 的倍数特征末两位是 4（或 25）的倍数
  • 8 / 125 的倍数特征末三位是 8（或 125）的倍数
  • 质数与合数质数只有 1 和它本身两个因数；1 既不是质数也不是合数20 以内质数：2 3 5 7 11 13 17 19
  • 最大公因数 × 最小公倍数(a, b) × [a, b] = a × b
  • 互质数(a, b) = 1两数互质时，[a, b] = a × b
  • 倍数关系若 a 是 b 的倍数，则 (a, b) = b，[a, b] = a

三、分数、小数与百分数10 条

  • 分数除法ab ÷ cd = ab × dc
  • 带分数化假分数cab = cb + ab
  • 分数与小数互化分数 → 小数：分子 ÷ 分母小数 → 分数：0.a = a10，0.ab = ab100
  • 百分数互化小数 → 百分数：×100%百分数 → 小数：÷100
